# KIS 현재가·시세 집계 추가 전환 보고

이 문서는 현재가 전환의 구현·로컬 검증 결과입니다. 사용자는 앞선 분석 확장과 이번 현재가 전환의 최종 검사 통과 후 GitHub 저장·운영 배포를 승인했습니다. 실제 배포 SHA와 접속 검증 결과는 배포 완료 보고에서 구분합니다.

## 변경

- 웹사이트 정상 경로의 현재가·등락·거래량·거래대금·시가·고가·저가를 KIS 현재가 REST 단일 응답으로 전환했습니다.
- KIS /uapi/domestic-stock/v1/quotations/inquire-price, FHKST01010100, 요청 시장 J를 사용합니다. 기존 KIS 일봉·차트와 요청 시장을 맞추며 NX/UN으로 넓히지 않습니다.
- 응답 stck_shrn_iscd를 검증합니다. 없거나 다르면 사용하지 않습니다.
- 원천 거래일·체결 시각·종목명은 공식 현재가 응답에서 제공하지 않으므로 만들지 않습니다. 실제 조회 시각만 기록하며 웹소켓 실시간 시세라고 표시하지 않습니다.
- 요청 범위 KRX와 실제 응답 시장 범위 미확인을 구분합니다. KOSPI/KOSDAQ 명칭으로 KRX/NXT 범위를 추정하지 않습니다.
- 현재가 실패 시 Naver 대체·만료 캐시 재사용이 없습니다. 화면 현재가는 null이며 상세 계산이 KIS 최근 일봉 종가를 쓴 경우에만 별도 대체값·기준일을 표시합니다.
- 현재가 응답의 외국인 수량은 분석 수급으로 쓰지 않습니다. 검증·선택한 KIS 수급 경로만 유지합니다. KIS 수급을 Naver 일별 수급으로 잘못 표시하던 진단 별칭도 KIS 경로에서 차단합니다.
- 뉴스·종목 목록·이름 검색은 기존 범위입니다. 종목명은 가격 응답에 섞지 않고 기존 목록의 표시명을 사용할 수 있습니다.

## 숫자 매핑과 정밀도

- stck_prpr → 현재가, prdy_vrss/prdy_ctrt → 등락 금액/비율
- acml_vol → 거래량, acml_tr_pbmn → 거래대금
- stck_oprc/stck_hgpr/stck_lwpr → 시가/고가/저가
- 국내 J 주식의 KRW/SHARES 계약과 KRX 기본 단위를 사용하며 원문에 억·백만 등의 배수를 추가하지 않습니다. 개별 REST 거래대금 단위 상세와 실제 운영 응답 대조를 완료했다고 주장하지 않습니다. 세부 일차자료·확인 범위는 kis-quote-source.md에 기록했습니다.
- 0 거래량/거래대금과 결측을 구분합니다. 가격×거래량으로 거래대금을 만들지 않습니다.
- 안전 정수 범위 밖의 정확한 문자열은 원문으로 보존하고 계산용 number는 null로 둡니다. 이미 정밀도를 잃은 JSON 숫자를 복원하지 않습니다.
- 등락 소수도 숫자 왕복 시 값이 달라지면 null과 원문을 남깁니다. 이미 부호가 있는 값을 보존하고 부호 코드와 모순되면 보류합니다. 확인되지 않은 양수 하락 크기를 임의 음수화하지 않습니다.
- OHLC가 모순되면 해당 OHLC를 보류합니다. 다른 응답이나 일봉 값으로 빈 집계 항목을 채우지 않습니다.

## 호출·캐시

현재가 요청은 종목당 데이터 GET 1회·한 시도·15초 중단 신호입니다. 같은 종목의 진행 요청과 캐시를 공유합니다. 기본 TTL은 기존 KIS 캐시 설정의 15초(기존 설정 최소 5초)이며 원래 조회 시각을 보존합니다. 정상 현재가만 캐시하고 실패·만료 시 오래된 가격을 반환하지 않습니다.

실제 데이터 HTTP 직전만 요청 수를 계산합니다. 캐시와 동시 공유는 새 데이터 호출 0회입니다. 기존 토큰·직렬 큐·속도 제한을 사용합니다. 필요한 OAuth는 기존 별도 경로이며 데이터 GET 횟수에 포함하지 않습니다. 새 인증값·권한 설정을 추가하거나 비밀값을 읽지 않았습니다. 자동 수집 일정·예산은 바꾸지 않았습니다.

차트 D/W/M/Y는 이전 구현처럼 선택 주기마다 별도 최대 1페이지·100봉·한 시도입니다. 현재가·일봉·화면 차트는 같은 KIS라도 서로 다른 응답/관측 시점일 수 있으며 값의 동시성을 보장하지 않습니다.

- 최종 전체: 147개 테스트 파일, 3,089개 통과, 실패/skip/취소 0. 외부 통신 차단 가상 검사, 약 203.80초.
- 최종 프런트 빌드: 통과. 500 kB 번들 경고는 남습니다.

- 정상 연속 quote/detail/AI는 캐시·동시 공유로 현재가 원천 HTTP 1회, 같은 뉴스 묶음 1회임을 검사했습니다.
- 심볼 불일치·실패·결측·0·거대한 정수·소수 정밀도·원천 날짜 미제공·동일 응답·수급 결측·상세 종가 대체와 헤드라인 null 분리를 검사했습니다.
- 기존 분석 확장·패턴·파동·조건부 시나리오·차트/인증/수급 안전 검사를 포함했습니다. 검사 삭제·skip·외부 API 차단 해제로 통과시키지 않았습니다.

실제 금융·계좌·주문·유료 AI·토큰 발급 API 호출은 하지 않았습니다. 실제 운영 값의 정확성·정밀도·가용성, 수익성은 미검증입니다. 배포 후에도 공개 로그인·health·정적 자산과 배포 SHA만 확인하며 실제 종목 분석 버튼은 누르지 않습니다.
