# 저장 관찰 기록의 최신성 재검증 V1

이 문서는 최초 V1 검증 근거다. 이후 OBSERVATION_V2의 근거 보존과 OBSERVATION_FRESHNESS_V2의 요청/응답 구분은 [관찰 근거 보존 문서](observation-evidence.md)에 정리했다. 과거 원본과 V1 재검증 기록은 변경하지 않는다.

관찰 데이터 검증·표시만 변경한다. 인증/요청 제한/전략 계산/주문 권한을 변경하지 않는다.
평가 시점은 원본 `receivedAt`, 재검증 실행 시점은 별도 `revalidatedAt`이다.
원본 ID·SHA256·정책 `OBSERVATION_FRESHNESS_V1`을 새 Git 제외 기록에 남긴다.
원본 입력 수치와 당시 전략 계산은 보존하며, 최신성을 승인한 계산으로 표현하지 않는다.

## 근거와 적용 범위 (2026-09-24 확인)

후속 확인: [실제 자료 확보 계획의 거래일 근거](observation-eod-data-plan.md#거래일-근거-확인한-휴장과-미확인-개장을-구분)에 KASI 월력요항과 KRX 휴장 규칙을 연결했다. **9/24~27 KOSPI 휴장은 확인**, 9/22·23 개장/특별 세션은 별도 확인 대상이다. 아래의 ‘미확인’은 최초 검증 당시 기록이며, 이제 모든 날짜 근거가 없다는 뜻으로 읽지 않는다. 전체 세션 캘린더와 일봉 완성은 여전히 미확인이고, 런타임 캘린더나 과거 기록을 변경하지 않았다.

- [KRX 공식 연별일정](https://www.krx.co.kr/contents/MKD/01/0110/01100303/MKD01100303.jsp): 2026년 다운로드 선택은 확인했으나 공개 문서 추출 결과에서 날짜별 주식 휴장·특별 세션 항목을 확보하지 못했다.
- [KRX 주식 거래 안내](https://global.krx.co.kr/contents/GLB/01/0109/0109000000/guide_to_trading_in_the_korean_stock_market.pdf): 정규장 09:00~15:30 안내를 확인했다. 오래된 일반 안내만으로 2026년 개별 날짜·시간외 세션 적용을 확정하지 않는다.
- 파생상품 모의거래 연휴 안내를 주식 실거래 캘린더로 대신 사용하지 않았다.
- 실제 캘린더 적용 기간: **미확인(null)**. 공식 날짜별 근거가 없으므로 실제 거래일 배열은 비어 있다. 주말 제외 계산·9월 24일 한 날짜 예외·제3자 휴일 달력은 사용하지 않는다. 9월 23일 자료를 하루 전이라는 이유만으로 STALE 처리하지 않는다.
- 기존 `tradingStrategy.js`는 현재가/일봉 지표/거래량/수급/뉴스를 모두 사용하지만, 장마감 전용 모드·현재가 지연 한도·뉴스 유효기간을 명시하지 않는다. 기존 종합 전략을 장마감 전략으로 바꾸지 않고 전체 판단 보류를 유지한다.

## 데이터별 기준

| 입력 | 용도와 판정 |
| --- | --- |
| 일봉·일봉 거래량 | 확인된 시장/세션 캘린더의 최근 완성 거래일과 비교. 원본 종목·단위·시장·완성 근거가 모두 있어야 장마감 분석 자료로 USABLE. 초 단위 시각은 필수가 아님. 확인된 더 오래된 거래일은 STALE. 미완성 세션·누락 근거는 UNKNOWN. |
| 현재가 | 원본 가격 필드·가격 종류·체결 시각 의미·시장 범위 필요. 공급자 갱신 시각/수신 시각은 체결 시각이 아님. 기존 전략의 허용 지연 계약이 없어 UNKNOWN. |
| 수급 | 집계 거래일·주 단위·시장 범위·집계 구간·잠정/확정 의미 필요. 기존 전략의 집계 최신성 계약 미정으로 UNKNOWN. |
| 뉴스 | 기사별 발행 시각과 전략 뉴스 유효기간 필요. 둘 중 하나라도 미확인이면 UNKNOWN. `hasCautionSignal=false`를 악재 없음으로 인정하지 않음. |

시장 불일치/불명확은 별도 사유로 남긴다. 실제 기록은 관찰 대상 `005930`과 정규화 수치만 확인 가능하며, 원본 요청/응답의 종목·시장·가격 필드, 기사별 시각이 저장되지 않았다. 현 코드의 요청 파라미터로 과거 응답을 복원하지 않는다. `sourceIntegrity.complete`는 숫자/날짜 검증이지 세션 종료 증거가 아니다.

`USABLE`은 해당 자료 용도에 한정된다. 전략 평가 시점 계약과 다른 필수 입력의 UNKNOWN을 해제하지 않는다. `riskReady=false`, `ledgerInputReady=false`, 거래 허가 미평가 / 주문 기능 미연결 유지.

## 실행 (외부 요청 없음)

프로젝트 루트에서 `node -r ./tests/helpers/local-only.cjs scripts/revalidate-observation.cjs 3b7d655e-bcb7-44d7-b1d3-57776fa6b333`.
기존 `.local/strategy-observations/live-once/<id>.json`만 읽고 `revalidation/<새 ID>.json` 및 HTML을 배타적으로 생성한다. JSON과 같은 ObservationResult UI를 정적 HTML로 렌더링하며 스크립트/외부 자원이 없다. HTML을 로컬에서 열면 데이터별 사유를 확인할 수 있다. 서버/환경변수/토큰 로딩 없음.

합성 캘린더는 `testData=true` 테스트에만 주입할 수 있다. 실제 기록에는 주입이 거부된다. 휴장일 전 완성 일봉 PASS 테스트는 **합성 테스트 결과**이며, 실제 기록의 완성 일봉을 입증하지 않는다. 실제 재검증에서는 날짜 차이만으로 STALE 처리하지 않지만 저장되지 않은 근거는 UNKNOWN으로 남는다.
