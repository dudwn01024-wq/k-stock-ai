## 1. 추천 추세·거래량의 KIS 전환

1. **기존 문제/제약:** 추천은 Naver 일별 자료, 상세 분석은 KIS 일봉을 써서 원천이 달랐습니다.
2. **변경 방식:** 기존 KIS 일봉 경로에서 30봉을 받으며 같은 추천의 빠른 선별→상세 계산은 동결된 동일 스냅샷을 재사용합니다. 정확한 종목·기간·J/D/0·TTL 조건이 맞는 기존 130봉 캐시도 재사용합니다. 한 페이지·한 시도이며 Naver 일봉 대체는 없습니다. 기존 계산식·점수는 유지합니다.
3. **화면 변화:** 표시 현재가는 KIS 현재가 조회 스냅샷, 추세·거래량 계산 종가는 KIS 일봉으로 구분합니다. 출처·거래일·조회 시각이 다를 수 있음을 유지합니다.
4. **쉬운 예:** KIS 현재가 조회값 10,100원과 KIS 일봉 종가 10,000원이 있으면 분석은 후자로 계산하지만 현재가를 바꾸지 않습니다. 추세는 종가 ≥ MA5 ≥ MA20, 거래량은 최신 봉과 직전 20봉 평균을 비교합니다. 최신 봉은 평균에서 제외합니다.
5. **검증/한계:** 20/21봉, 0/null, 09시 이전·장중 거래량 보류, 잘못된 원천 날짜·OHLC, 호출 상한·캐시·동시 요청 재사용을 가상 검사했습니다. 기존 KIS 경로가 지원하지 않는 영문 포함 종목코드는 대체하지 않고 부족으로 남깁니다. 실제 데이터 정확성은 미검증입니다.

추가 혼합 방지: 새 KIS 기준가격을 기존 Naver 전용 성과 수집기와 섞어 T+1/T+5/T+20 수익률을 계산하지 않습니다. KIS 전용 성과 수집 연결 전에는 이유를 표시하며 보류합니다. 기존 Naver 이력은 보존하고 수집 범위를 확대하지 않았습니다.

## 2. AI 수급 중복 제거

1. **기존 문제/제약:** AI 입력에 원래 Naver quote 수급과 실제 선택된 KIS 수급이 함께 들어갈 수 있었습니다.
2. **변경 방식:** AI 직전 실제 분석에 사용한 검증된 KIS 수급 한 묶음만 남깁니다. 중첩된 수급 숫자·상태·이전 설명도 정리합니다. KIS가 없거나 종목·유효성이 맞지 않으면 unavailable과 이유를 줍니다. 현재가·거래량·거래대금·OHLC 출처는 유지합니다. 저장되는 추천 AI 입력과 실제 전송 입력도 같습니다.
3. **화면 변화:** 해설 기준의 수급 출처·거래일·조회 시각을 표시합니다. 날짜 차이, 외국인/기관 매매 방향 차이, 검증 불가를 구분합니다. 이후 캐시만 바뀌면 해설은 원래 관측 기준임을 알리며 자동 AI 재호출은 하지 않습니다.
4. **쉬운 예:** Naver 외국인 +100주와 KIS -20주가 함께 있던 경우 실제 사용한 KIS -20주만 줍니다. KIS 기관 +10주라면 외국인/기관 방향 차이이고, 날짜 차이는 별도 경고입니다.
5. **검증/한계:** 실제 라우트→프롬프트→가짜 Gemini 전송 본문을 캡처해 반대 수급, KIS 결측·잘못된 종목·합계·날짜, 캐시 갱신을 검사했습니다. 실제 Gemini 재실행은 하지 않았으며 과거 저장 이력을 새 사실로 덮어쓰지 않습니다.

2. **변경 방식:** 2파의 원점 침범 금지, 3파의 전진·최단 금지, 일반 충격파의 4파/1파 비중첩 등을 검사합니다. 앞선 유효 5파와 연결한 ABC 조정 외형 후보를 추가했습니다. 되돌림 38.2%·50%·61.8%, 확장 1배·1.618배는 참고값이며 50%는 중간값이라고 구분합니다. 여러 카운트를 보존합니다.
3. **화면 변화:** 파동별 날짜·가격·확인 가능 날짜, 규칙의 충족/위반/아직 미확인, 되돌림·확장 참고값, 실제 관측 무효 가격·부등호·날짜와 이유를 펼쳐 봅니다.

5. **검증/한계:** 상승·하락, 규칙 위반, ABC 미완성·무효, 복수 카운트, 산술·결측, 미래 봉 차단·과거 재생을 검사했습니다. 스냅샷 판정이며 하위 5-3-5 분할, 모든 조정 유형, 대각선·단축 5파·실시간 연속 추적은 지원하지 않습니다. 과거 모양과 그 이후 계속 해석의 무효 조건은 별개입니다.

## 5. 분석용 가격 시나리오

1. **기존 문제/제약:** 기존 하나의 가격 기준만으로 새 패턴들의 조건·무효 지점·상충 해석을 설명하기 어려웠습니다.
2. **변경 방식:** 실제 패턴 경계·도형 높이에서 조건부 진입 참고 경계, 구조 무효/손절 참고 경계, 목표 참고 구간을 만듭니다. 돌파·이후 재시험·변동성 맥락을 구분합니다. 기존 가격 기준과 비교하며 후보 평균이나 최고 손익비 자동 선택은 하지 않습니다. 파동 피보나치만으로 진입/목표를 정하지 않습니다.
3. **화면 변화:** 방향·조건·근거와 기존 가격을 나란히 표시합니다. 종가 구조 무효와 일봉 고가/저가의 경계 접촉은 구분합니다. 반대 방향 후보도 충돌 사유와 함께 보존합니다.
4. **쉬운 예:** 경계 10,000원·무효 참고 9,800원·측정 목표 11,000원은 조건부 참고 시나리오입니다. 10,300원으로 갭 상승해도 10,000원에 체결됐다고 가정하지 않습니다.
5. **검증/한계:** 실제 새 패턴·파동 출력 연결, 방향·가격 순서·0분모·단위·미래 시점·갭·같은 일봉 안 손절/목표 동시 접촉·상충 대안을 검사했습니다. 호가 규칙 미확인은 반올림하지 않은 참고값입니다. 실제 체결·수익성·성공적 백테스트를 검증하지 않았습니다.

## 6. 손익비와 추천/상세 계산의 차이

1. **기존 문제/제약:** 추천 후보와 상세 분석의 가격 산출법이 다른데 하나의 계산처럼 오해할 수 있었습니다.
2. **변경 방식:** 기존 두 방식을 유지하고 새 시나리오에 방향을 검증한 손익비를 별도로 제공합니다. 기존 판정 문턱·가중치는 유지합니다.
3. **화면 변화:** 기존 상세 가격과 조건부 시나리오를 비교하고 비용 전 값이며 승률·실현 수익률이 아님을 표시합니다.
4. **쉬운 예:** 상승에서 진입 10,000·손절 9,800·목표 11,000원이면 (11,000−10,000)/(10,000−9,800)=5입니다. 하락은 (진입−목표)/(손절−진입)입니다.
5. **검증/한계:** 가격 순서·양수 위험 폭·유한값·0분모·명시 비용·음수 순보상·상충을 검사했습니다. 수수료·세금·슬리피지 기본값은 없습니다. 현재 화면에는 실제 비용 입력 설정을 추가하지 않았으므로 gross입니다. 코드에서 검증된 명시 주당 비용을 받을 때만 net을 따로 계산할 수 있습니다.

**추천 후보 계산(유지):** MA5·MA20·최근 20봉 저가 중 종가 이하 가장 가까운 값을 진입 기준, 최근 20봉 최고가를 상단, MA20·최근 20봉 저가 중 진입보다 낮은 가장 가까운 값을 하단으로 씁니다. 추세·거래량·수급 통과와 유효한 가격 순서가 필요합니다. 현재 KIS 종가 기준 남은 보상/위험과 진입 기준 보상/위험을 각각 계산합니다. 현재가 기준 비율 1 이상 등 기존 추천 등급 기준을 유지합니다.

**상세 계산(유지):** 실제 피벗을 모은 지지·저항을 씁니다. 진입=가까운 지지, 목표=가까운 저항, 하단=지지−ATR14×0.5, 손익비=(저항−지지)/(지지−하단), 최소 2 등 기존 조건을 유지합니다. 저항·ATR 등이 없으면 숫자를 채우지 않습니다. KIS로 원천을 통일해도 추천/상세/패턴 시나리오 값은 계산법이 달라 서로 다를 수 있습니다.

## 7. 화면 차트: KIS 일·주·월·년, 분봉 제외

1. **기존 문제/제약:** 화면은 Naver 일별 자료·기간 길이 선택, 실제 분석은 KIS 일봉이어서 원천과 봉 단위가 혼동될 수 있었습니다.
2. **변경 방식:** KIS 공식 API D/W/M/Y 원천 봉을 받습니다. 일봉 130개를 묶지 않습니다. 최대 100봉·한 페이지·한 시도, 기존 토큰·속도 제한 큐, 기간별 캐시를 사용합니다. 서버 데이터 요청 15초·화면 20초 제한이며 자동 재시도하지 않습니다. 캐시/동일 진행 요청 공유는 추가 원천 요청 0회입니다. 기존 토큰이 없을 때 OAuth는 별도이며 데이터 요청 수와 구분합니다.
3. **화면 변화:** 일/주/월/년봉, 확대·축소·좌우 이동·초기화, 받은 자료 내 범위 선택, 십자선 OHLCV·거래량, MA5/20/60 토글을 제공합니다. 기본 터치는 세로 스크롤을 유지하고 명시적 끌기 모드에서 가로 이동합니다. 키보드 방향키/Home/End/확대축소, 오류·조회 취소·수동 재조회도 지원합니다. 종목/주기 변경 시 이전 봉을 비우고 늦은 응답을 버립니다.
4. **쉬운 예:** 주봉 MA20은 주봉 종가 20개의 평균입니다. 상세 분석 MA20은 일봉 20개 평균입니다. 월봉으로 표시를 바꿔도 기존 일봉 분석·AI는 다시 실행하지 않습니다. 년봉이 20개면 MA60은 미확인입니다.
5. **검증/한계:** 가상 원천 읽기→서버→요청 검증→화면을 구분해 4주기·중복·OHLCV·0/null·종목/범위·잠정 봉·취소·오류·시간 제한·재시도·늦은 응답을 검사했습니다. 로컬 브라우저에서 확대/이동/키보드/주기/MA와 모바일 폭의 가로 넘침·스크롤 모드를 확인했습니다. 실제 휴대폰 터치와 실제 운영 KIS 응답은 미검증입니다.

## 분석 종류와 자료를 가져오는 방법

추천의 기본 조건은 **4개(추세·거래량·수급·뉴스)**입니다. 상세 판정은 **12개(기술 7 + 시장 3 + 가격 2)**입니다. 이 둘은 단계가 겹치므로 16개 독립 분석이라고 더하지 않습니다. 종합 점수·등급은 이 결과를 합친 값이며, AI는 별도 설명입니다. 새 패턴·파동·조건부 시나리오는 별도 관찰 결과로 기존 점수·판정에 추가 투표하지 않습니다.

| 영역 | 실제 입력·출처 | 코드상 조회·보관 방식 | 부족할 때 |
|---|---|---|---|
| 추천 종목 목록 | Naver 시가총액 목록 | 기존 legacy50/expanded500 범위 유지, 실행 결과 재사용 조건 유지 | 목록/종목 검증 실패 표시 |
| 추천 추세·거래량 | KIS 일봉 30개 | 기존 OHLCV 경로·캐시, 한 페이지·한 시도, 선별→상세 동일 관측 재사용 | Naver 대체 없이 부족 |
| 현재가·거래량·거래대금·OHLC 시세 집계 | KIS inquire-price 단일 응답 | 원천 거래일·시각 미제공은 null, 실제 조회 시각만 보존. 다른 응답 보충·Naver 대체 없음 | null과 실제 0·정밀도 한계 구분 |

| KIS 장중·장후 수급 | 장중 투자자 추정/장후 투자자 일별 자료 | 기존 일정·캐시·호출 예산 유지. 화면 읽기·AI는 캐시를 해석하며 새 수급 수집을 임의 시작하지 않음 | 날짜·원천 시각 없으면 미확인, 계획 시각을 원천 시각으로 쓰지 않음 |
| 새 패턴·파동·시나리오 | 이미 받은 KIS 일봉 중 같은 KST 날짜 봉을 제외한 완료 봉 | 추가 금융 호출 없음. 피벗 뒤 2봉 확인과 과거 시점 재생 | 후보 없음과 원천/기간 부족을 구분 |

이동평균·RSI·MACD·볼린저·ATR·지지저항·캔들·차트·파동은 같은 가격 자료를 여러 방법으로 보는 계산입니다. 추가 웹 크롤링이나 DART 재무분석을 새로 붙인 것이 아닙니다. AI에 새 관찰 맥락이 포함될 수 있으므로 실제 호출당 입력 토큰 비용이 완전히 같다고 보장하지 않습니다. 이번 검증에서는 실제 AI를 호출하지 않았습니다.

스케줄은 코드의 설정과 실제 실행 증거를 구분해야 합니다. 기존 장중 관측 슬롯과 장후 창·예산을 바꾸지 않았습니다. 이번 로컬 작업은 해당 스케줄이 운영에서 모든 회차 성공했다는 검증이 아닙니다.
